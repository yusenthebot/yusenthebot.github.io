# Yusen Terminal v7

Personal portfolio for Yusen Xie — Robotics & AI Engineer at CMU, co-founder of Vector Robotics. Interactive terminal interface with an animated robot companion (V).

## Stack

- React 19 + Vite 8
- Tailwind CSS 4
- Three.js / React Three Fiber (3D robot, post-processing)
- GSAP 3 (animations)
- Zustand 5 (state)

## Development

```
npm install
npm run dev
```

## Build

```
npm run build
```

Output goes to `dist/`. Production build is deployed to GitHub Pages automatically on push to `main` via `.github/workflows/deploy.yml`.
